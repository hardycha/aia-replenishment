# ISSUE: ILP 배분 로직과 실제 보충배분 목적 간의 간극

> 발견일: 2026-05-27  
> 상태: **Open — 넥스트 스텝 논의 필요**  
> 관련자: Hardy, Colly

---

## 1. 현상

ILP 서버에 실 데이터(forecast + 매장재고 + 창고재고)를 보내면, **거의 모든 스타일에서 배분량 0**을 반환한다.

## 2. 원인 (Colly 확인 완료)

ILP의 제1 목표는 **"PRED_SC_QTY(주간 SC 판매 예측) 수량과 전체 매장 재고 합의 간극을 줄이는 것"**으로 설계되어 있다.

- `PRED_SC_QTY` = 다음 주 이 SC가 전 매장 합쳐 팔릴 예측 수량
- 현재 전체 매장 재고 합 > PRED_SC_QTY인 경우 → **"이미 충분하다"** → 추가 배분 불필요로 판정

예시:
```
DMTS71063 BKS:
  PRED_SC_QTY (주간 예측): ~0.47개
  전체 매장 재고 합: ~520개
  → 매장 재고가 예측의 1,100배 → ILP: "배분 불필요"
```

## 3. 실제 보충배분 목적과의 간극

| 구분 | ILP 현재 설계 | 실제 보충배분 목적 |
|------|-------------|-----------------|
| 목표 | 예측 판매량과 매장 재고 합의 간극 최소화 | 각 매장의 사이즈별 여유재고가 유지되도록 보충 |
| 기준 | 전체 매장 재고 합 vs SC-Total 예측 | 개별 매장의 사이즈별 재고 vs 필요 보충량 |
| 결과 | 매장 재고 합 > 예측이면 배분 0 | 특정 매장/사이즈에 재고 부족하면 보충 필요 |

**핵심 간극**: 실제 보충배분에서는 "한 주 동안 매장 재고를 다 파는 수준"으로 배분하는 게 아니라, **사이즈별·컬러별 여유재고가 남아있게끔 보충**하는 것이 목적. 현재 ILP는 "전체 재고가 예측보다 많으면 추가 배분 불필요"로 판단하므로, 개별 매장의 사이즈 결품 상황을 해소하지 못한다.

## 4. 넥스트 스텝 (검토 필요)

아래 방향 중 하나를 Colly와 협의하여 결정해야 함:

### Option A: ILP 서버 측 로직 조정
- ILP의 목적함수를 "전체 재고-예측 간극 최소화"에서 **"매장별 사이즈 커버리지 균형 최적화"**로 변경/추가
- 장점: 우리 시스템 변경 최소, ILP가 원래 의도대로 동작
- 단점: Colly 측 ILP 재설계 필요, 일정 영향

### Option B: forecast 값을 보충배분용으로 변환
- PRED_SH_SCS_NORM_QTY를 보충 목적에 맞게 스케일링하여 ILP에 전달
- 예: "매장별 적정 재고 수준"을 forecast로 보내는 방식
- 장점: ILP 서버 변경 없음
- 단점: 변환 로직 설계 필요, 예측의 의미가 변질될 수 있음

### Option C: 보충배분 전용 예측 컬럼 신설
- Snowflake에 보충배분용 예측 컬럼을 별도로 적재 (예: PRED_REPLENISH_QTY)
- "매장별 사이즈별 적정 보충 수량"을 직접 예측
- 장점: 가장 깔끔한 해결
- 단점: 예측 모델 추가 개발 필요
