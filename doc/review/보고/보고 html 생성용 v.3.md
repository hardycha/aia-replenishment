## 1. 프로젝트 목적

### 1.1 현재의 문제

F&F의 보충배분은 현재 유통 MD가 매주 수기 엑셀로 집행하고 있습니다. 이 방식에는 세 가지 구조적 한계가 존재합니다.

**① 담당자별 판단 기준 분산**

담당자가 바뀌거나 SKU 수가 늘어날수록 배분 품질이 불안정해집니다. 동일한 상황에서도 담당자마다 판단 기준이 달라 결과가 다르며, 이 기준이 조직 내에 명시적으로 문서화되어 있지 않습니다.

**② 베스트셀러 대응 구조적 취약**

잘 팔리는 SC일수록 재고가 빠르게 소진되지만, 수기 배분으로는 판매 속도를 선제적으로 반영해 물량을 집중시키기 어렵습니다. 결과적으로 판매 기회 손실이 발생합니다.

**③ 반복 작업 공수 과다**

스타일 수 x 매장 수 x 사이즈 수의 조합을 매주 반복 계산합니다. 단순 기준의 반복 판단에 MD가 시간을 쏟고 있어, 고부가가치 의사결정에 집중할 수 없습니다.

### 1.2 프로젝트 목적

> **"AI 기반 수요 예측 + 수학적 최적화로 보충배분 의사결정을 자동화하여, MD의 판단은 예외 처리와 최종 확인에 집중할 수 있는 구조를 만든다."**

- **베스트셀러 재고 부족 방지**: 주간 판매 예측치를 기반으로 잘 팔리는 SC에 선제적으로 물량을 집중 배분
- **MD 배분 의사결정 효율화**: 시스템이 최적 배분 수량을 제안하고, MD가 검토·조정·확정하는 구조로 전환

### 1.3 적용 범위

- 초기 적용: **Discovery 의류, MLB CP66,CP77** (M 브랜드)
- 확장 대상: (Discovery, MLB, MKids, Duvetica, Sergio Tacchini)의 전체 아이템군

## 2. 효용성 검증 — MD가 하는 일을, AIA로 더 빠르게 할 수 있는가?

> Discovery 의류 카테고리에 대해 3주간(W1~W3) MD의 실제 배분 데이터와 ILP 시뮬레이션 결과를 매장 재고·판매 데이터와 대조 검증했습니다.

**검증 전 참고사항**: 본 검증 기간(4월 말~5월 중순)은 **26S 시즌 초입**으로, 매장에 이미 시즌 초도물량이 투입되어 있어 보충배분 물량 자체가 크지 않은 시기입니다. 따라서 배분 건수와 수량의 절대 규모보다는, **배분의 방향성과 품질이 유사한 수준인지**에 초점을 맞추었습니다. 26SS 판매가 본격적으로 쌓이면서 배분 규모가 커지는 시점에 대해서는 **위클리 단위로 실배분과 ILP 결과를 지속 비교·적재하여 추이를 팔로우업**할 예정입니다.

### 2.1 데이터 연동 검증

AIA 시스템은 기간계 시스템 SERP와의 데이터 인터페이스를 통해 매장재고, 창고재고, 판매이력을 직접 연동합니다. 데이터 정합성 검증이 완료되었습니다.

### 2.2 배분 품질 비교 — MD와 ILP는 유사한 수준의 보충을 하는가?

MD가 실제로 배분한 매장에 대해, **배분 후 잔여재고(배분 전 재고 + 배분량 - 실판매)**가 적정 수준인지를 비교했습니다.

#### MD가 배분한 매장의 보충 품질 (W3 26S, 81개 스타일×매장 페어)

| 잔여재고 구간 | MD 배분 후 | ILP 배분 후 |
|-------------|----------|-----------|
| 품절위험(≤0) | 2개 (2.5%) | 4개 (4.9%) |
| 적정(1~2) | 1개 (1.2%) | 1개 (1.2%) |
| 여유(3~5) | 27개 (33.3%) | 27개 (33.3%) |
| 과잉(6+) | 51개 (63.0%) | 49개 (60.5%) |

**MD가 배분한 매장에서 MD와 ILP의 보충 결과는 유사합니다.** 시즌 초입이라 대부분의 매장이 이미 충분한 재고를 보유하고 있었고, MD의 보충 판단도, ILP의 보충 판단도 이 현실을 반영하고 있습니다. 과배분 문제는 양쪽 모두 사실상 없습니다.

#### 전체 판매 활성 매장 기준 (1,456개 스타일×매장)

| 잔여재고 구간 | MD 기준 | 비율 | ILP 기준 | 비율 |
|-------------|--------|------|---------|------|
| 품절위험(≤0) | 59개 | 4.1% | 61개 | 4.2% |
| 적정(1~2) | 14개 | 1.0% | 12개 | 0.8% |
| 여유(3~5) | 78개 | 5.4% | 79개 | 5.4% |
| 과잉(6+) | 1,305개 | 89.6% | 1,304개 | 89.6% |

> 시즌 초입으로 대부분의 매장이 이미 충분한 초도물량을 보유하고 있어, 보충배분 자체가 소규모로 이루어진 시기입니다. 이 조건에서 MD와 ILP의 보충 결과가 유사하다는 점이 핵심입니다.

> **핵심 결론: AIA는 MD가 현재 수행하고 있는 보충배분과 유사한 품질의 결과를 산출합니다.** 차이는 품질이 아니라 **속도와 편의성**입니다. MD가 스타일별로 수기 엑셀 작업을 해야 하는 것을, AIA 화면에서 버튼 클릭으로 동시에 처리할 수 있습니다.

### 2.3 ILP 시스템 안정성 검증

W3 시즌(26S) 76건에 대해 ILP 서버를 실제 호출한 결과, **76건 전건 정상 응답**을 반환했습니다(OPTIMAL 75건 + FEASIBLE 1건). ILP는 매장의 현재 재고가 충분한 경우 추가 배분을 자동으로 억제하여, 불필요한 과잉배분을 방지하는 로직이 정상 작동함을 확인했습니다.

| 지표 | 값 |
|------|-----|
| ILP 호출 건수 | 76건 (W3, 26S) |
| 정상 응답 | 76건 전건 (OPTIMAL 75 + FEASIBLE 1) |
| 평균 재고 커버리지 (실판매 기준) | 4.3주 |
| 중간값 재고 커버리지 | 3.5주 |

**핵심 장점 2: 판단 일관성** — 동일한 인풋에 동일한 결과를 보장합니다. MD의 컨디션이나 업무 부하와 관계없이, 매주 동일한 기준으로 배분이 실행됩니다.

**핵심 장점 3: 다변수 동시 고려** — 창고재고 + 매장재고 + 예측수요 + 매장 우선순위를 수학적으로 동시 최적화합니다. 과잉배분 방지 로직이 자동 작동합니다.

## 3. 솔루션 구조

### 3.1 전체 흐름

```
┌─────────────┐     ┌─────────────┐
│  Snowflake  │     │   S-ERP     │
│ (판매이력·   │     │ (재고 마스터) │
│  예측 적재)  │     │             │
└──────┬──────┘     └──────┬──────┘
       │                   │
       ▼                   ▼
┌──────────────────────────────────┐
│     ① AI 수요 예측 (ML 서버)      │
│  SC-Total: 전체 판매 수량 예측     │
│  SC-Shop: 매장별 배분 비율 산출    │
└──────────────┬───────────────────┘
               │
               ▼
┌──────────────────────────────────┐
│  ② 수학적 최적화 (ILP 서버)       │
│  창고 가용재고 제약 내에서          │
│  매장별·사이즈별 최적 배분 수량 계산 │
│  입력: SERP 실시간 재고 API       │
└──────────────┬───────────────────┘
               │
               ▼
┌──────────────────────────────────┐
│  ③ 유통MD 화면 (보충배분-AIA)     │
│  배분 결과 확인·조정               │
│  → 엑셀 다운로드 → S-ERP 업로드   │
└──────────────────────────────────┘
```

- **Snowflake**: 판매 이력 데이터 저장, ML 예측 결과 적재
- **S-ERP (SERP)**: 매장·창고 실시간 재고를 API로 제공, 최종 배분 결과 업로드 대상
- **ML 서버**: Snowflake 데이터 기반 수요 예측 수행, 결과를 Snowflake에 적재
- **ILP 서버**: SERP 실시간 재고 + ML 예측값을 인풋으로 최적 배분 수량 계산
- **보충배분-AIA 화면**: MD가 결과를 확인·조정하고, S-ERP 업로드용 엑셀을 다운로드

### 3.2 유통MD 화면 — 2단계 구조

| 단계 | 화면 | 주요 기능 |
|------|------|----------|
| **1단계** | 매장 조정 | 예측 시각화, 배분 대상 매장 추가/제거, 배분 시뮬레이션 실행 |
| **2단계** | 피벗 상세 | AI 배분 결과 검토·수정, S-ERP 업로드용 엑셀 다운로드 |

### 4.3 향후 확장 — RT(Rotation) 매장 간 재고 이동

현재 AIA는 **창고 → 매장** 방향의 보충배분에 집중하고 있습니다. 그러나 실제 유통 현장에서는 특정 매장에 재고가 잠겨 판매되지 못하는 반면, 같은 상품이 다른 매장에서는 품절인 상황이 빈번하게 발생합니다.

향후 **RT(Rotation) 기능**이 포함되면, 매장 간 재고 이동까지 최적화할 수 있습니다.

- **잠자는 재고 활성화**: 판매가 느린 매장에 잠겨 있는 재고를 잘 팔리는 매장으로 자동 이동 제안
- **품절 기회손실 감소**: 창고에 재고가 없더라도 타 매장에서 여유 재고를 확보하여 판매 기회 유지
- **재고 회전율 개선**: 전체 매장의 재고가 고르게 소진되도록 유도하여, 불필요한 잔여 재고 발생을 최소화

> 보충배분(창고→매장) + RT(매장→매장)가 결합되면, F&F의 재고 배분은 **양방향 최적화 네트워크**로 전환됩니다.
