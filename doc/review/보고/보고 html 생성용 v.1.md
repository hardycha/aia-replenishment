## 1. 프로젝트 목적

### 1.1 현재의 문제

F&F의 보충배분은 현재 유통 MD가 매주 수기 엑셀로 집행하고 있다. 이 방식에는 세 가지 구조적 한계가 존재한다.

**① MD 개인 역량 의존**

담당자가 바뀌거나 SKU 수가 늘어날수록 배분 품질이 불안정해집니다. 동일한 상황에서도 MD마다 판단 기준이 달라 결과가 다르며, 이 기준이 조직 내에 명시적으로 문서화되어 있지 않습니다.

**② 베스트셀러 대응 구조적 취약**

잘 팔리는 SC일수록 재고가 빠르게 소진되지만, 수기 배분으로는 판매 속도를 선제적으로 반영해 물량을 집중시키기 어렵습니다. 결과적으로 판매 기회 손실이 발생합니다.

**③ 반복 작업 공수 과다**

스타일 수 x 매장 수 x 사이즈 수의 조합을 매주 반복 계산합니다. 단순 기준의 반복 판단에 MD가 시간을 쏟고 있어, 고부가가치 의사결정에 집중할 수 없습니다.

### 1.2 프로젝트 목적

> **"AI 기반 수요 예측 + 정수 최적화(ILP)로 보충배분 의사결정을 자동화하여, MD의 판단은 예외 처리와 최종 확인에 집중할 수 있는 구조를 만든다."**

- **베스트셀러 재고 부족 방지**: 주간 판매 예측치를 기반으로 잘 팔리는 SC에 선제적으로 물량을 집중 배분
- **MD 배분 의사결정 효율화**: 시스템이 최적 배분 수량을 제안하고, MD가 검토·조정·확정하는 구조로 전환

### 1.3 적용 범위

- 초기 적용: **MLB** (M 브랜드)
- 확장 대상: **5개 브랜드** (Discovery, MK, Duvetica, Sergio Tacchini)

## 2. 솔루션 접근 방식

### 2.1 전체 흐름

```
Snowflake (판매 이력 · 마스터 · 실시간 재고)
    ↓
① 수요 예측 모델 (ML)          ← Colly 담당
   SC-Total: LightGBM / TFT
   SC-Shop: TSB
    ↓
② 정수 최적화 서버 (ILP)        ← Colly 담당
   POST /optimize → 매장별 최적 배분
    ↓
③ 유통MD 화면 (Next.js)        ← Hardy 담당
   매장 조정 → 배분 시뮬레이션 → 엑셀 다운로드
```

### 2.2 수요 예측 모델

| 모델 | 테이블 | 알고리즘 | 역할 |
|------|--------|---------|------|
| **SC-Total** | `PRED_SC_W` | LightGBM / TFT | "이번 주 이 SC는 전 매장 합쳐 몇 개 팔릴 것인가" (절대 수량) |
| **SC-Shop** | `PRED_SH_SCS_W` | TSB | "총 예측 물량을 매장별·사이즈별로 어떤 비율로 배분할 것인가" (정규화 분포값) |

두 모델의 출력을 조합하면 **매장별·사이즈별 절대 예측 수량**을 도출할 수 있으며, 이 값이 ILP의 수요 입력값이자 MD 화면의 예측 시각화 원천이 된다.

### 2.3 유통MD 화면 — 2단계 전환 구조

| 단계 | 화면 | 주요 기능 |
|------|------|----------|
| **1단계** | 매장 조정 | 예측 시각화 확인, 배분 대상 매장 추가/제거, 배분 시뮬레이션 실행 |
| **2단계** | 피벗 상세 | AI 배분 결과 검토/수정, S-ERP 업로드용 엑셀 다운로드 |

기술 스택: Next.js 16 / React 19 / TypeScript / Tailwind CSS v4 / shadcn/ui / Recharts / Vercel 배포

## 4. 결과물 효용성 검증

> 보충배분 AIA의 결과물이 실제 배분 업무에 효용성이 있는지를 정량 검증한 결과입니다. 단순히 시스템이 "동작"하는 수준을 넘어, 기존 수기 배분 대비 왜 AIA가 필요한지를 데이터로 보여줍니다.

### 4.1 데이터 정합성 검증

> **핵심 메시지**: AIA 시스템은 Snowflake 분석계의 실시간 매장재고, 창고재고, 판매이력을 직접 연동합니다. MD가 수기로 확인하기 어려운 **전체 매장의 재고 현황을 동시에 파악**할 수 있으며, 분석 기반이 되는 데이터의 신뢰성이 확인되었습니다.

Discovery 의류 카테고리에 대해 3주간(W1~W3) 데이터 정합성을 검증했습니다. 매주 **57,000~61,000건**의 매장 x 스타일 재고 데이터가 정상 조회되었고, 창고에서는 주차당 **529~575건**의 스타일별 가용재고가 확인되었습니다. **268개 매장**에 걸친 **704개 스타일**을 전수 커버하고 있어, AIA가 보는 데이터는 MD가 일일이 확인할 수 없는 범위까지 포괄하고 있음이 입증되었습니다.

| 지표 | 값 |
|------|-----|
| 분석 대상 매장 수 | **268** |
| 분석 대상 스타일 수 | **704** |
| 주차당 매장 재고 데이터 건수 | **~60,000** |
| 주차당 창고 가용재고 건수 | **~550** |

### 4.2 현행 수동 배분의 구조적 한계 발견

> **핵심 메시지**: MD가 직접 배분할 때 발생하는 구조적 비효율을 데이터로 확인했습니다. 이는 MD 개인의 역량 문제가 아니라, **수백 개 매장을 동시에 최적화하는 것이 인간의 인지 한계로는 불가능하다는 구조적 문제**입니다.

#### 배분 방향성의 불일관성

실제 배분 데이터의 Spearman 상관계수를 분석한 결과, 주차별로 **완전히 다른 패턴**이 나타났습니다. W1에서는 +0.362(양의 상관), W2에서는 -0.242(음의 상관), W3에서는 +0.077(무상관)로, 매주 배분 판단의 방향성 자체가 일관되지 않았습니다. 이는 MD가 체계적인 기준 없이 주차마다 다른 판단 로직을 적용하고 있음을 시사하며, **시스템이 일관된 기준으로 배분을 제안해야 할 명확한 근거**입니다.

| 주차 | Spearman ρ | 해석 |
|------|-----------|------|
| W1 | **+0.362** | 재고 많은 곳에 더 배분 |
| W2 | **-0.242** | 재고 적은 곳에 더 배분 |
| W3 | **+0.077** | 무상관 |

#### Missed Pair — 놓친 배분 기회

"Missed Pair"란, **창고에 재고가 있고 매장 재고가 부족(3개 이하)한데도 배분되지 않은 매장-스타일 쌍**을 말합니다. 분석 결과 매주 **3,000~4,400쌍**의 Missed Pair가 발견되었으며, 이 중 **87~97%**는 창고에 충분한 재고가 있었음에도 배분이 이루어지지 않았습니다. 이것은 MD가 수백 개 매장의 개별 재고 상황을 동시에 파악하는 것이 물리적으로 불가능하기 때문이며, **ILP의 전역 최적화가 가장 잘 발휘될 수 있는 영역**입니다.

| 주차 | Missed Pair | 배분 가능 (창고 재고 충분) | 비율 | 배분 불가 |
|------|-------------|----------------------|------|---------|
| W1 | 4,120쌍 | **3,863쌍** | **93.8%** | 257쌍 |
| W2 | 4,399쌍 | **3,848쌍** | **87.5%** | 551쌍 |
| W3 | 3,065쌍 | **2,983쌍** | **97.3%** | 82쌍 |

<!-- 차트: Missed Pair 스택 바차트 (W1/W2/W3, 배분가능 vs 배분불가) -->

> W1 기준, 배분 가능했던 3,863쌍 중 상당수가 판매 기회를 놓쳤을 가능성이 높습니다. ILP는 이 전체 매장-스타일 매트릭스를 수학적으로 동시 최적화하여 이러한 누락을 체계적으로 해소합니다.

### 4.3 ILP 배분 시뮬레이션

> **핵심 메시지**: W3 시즌(26S) 76건에 대해 ILP 서버를 실제 호출하여 소급 시뮬레이션을 수행했습니다. ILP는 **75건 모두 OPTIMAL(최적해) 응답을 반환**했으며(성공률 98.7%), 매장별 재고 수준과 예측 수요를 동시에 고려하여 합리적인 배분 판단을 내렸습니다.

특히 주목할 점은 ILP의 **과잉배분 방지 로직**입니다. 매장의 현재 재고가 예측 수요를 이미 충족하는 경우, ILP는 추가 배분을 자동으로 억제합니다. 이는 수기 배분에서 발생하기 쉬운 "안전 재고 과적" 문제를 구조적으로 해소하는 메커니즘입니다.

| 지표 | 값 |
|------|-----|
| ILP OPTIMAL 성공률 | **98.7%** |
| 정상 최적해 도출 | **75/76건** |
| 평균 재고 커버리지 (실판매 기준) | **4.3주** |
| 중간값 재고 커버리지 | **3.5주** |

#### 실판매 기준 매장 재고 커버리지 분포

<!-- 차트: 재고 커버리지 분포 바차트 -->

| 구간 | 매장 수 | 비율 |
|------|--------|------|
| 2주 미만 | 736 | 20.9% |
| 2~4주 | 1,124 | 32.0% |
| 4~8주 | 1,147 | 32.6% |
| 8~12주 | 420 | 11.9% |
| 12주 이상 | 90 | 2.6% |

> 재고 커버리지 분포를 보면, 전체 매장의 약 **64%**가 2~8주 범위에 위치합니다. 이는 ILP가 과소배분도 과잉배분도 아닌, 적정 수준의 재고를 유지하는 방향으로 배분을 최적화하고 있음을 보여줍니다.

#### 시즌 구성 분석

<!-- 차트: 시즌 구성 도넛차트 -->

| 분류 | 쌍 수 | 비율 |
|------|-------|------|
| 당시즌 (26S/26N) | 2,928 | 38.8% |
| 이월 | 4,621 | 61.2% |

분석 대상 중 이월 시즌(61.2%)이 당시즌(38.8%)보다 많아, 이월 재고의 효율적 배분이 특히 중요합니다.

#### ILP 핵심 동작 원리

- 창고 재고 한도 내에서 배분 (초과 불가)
- 매장 재고가 예측 수요를 이미 충족 시 추가 배분 억제
- adjRank 기반 매장 우선순위 반영
- 사이즈별 독립 최적화

### 4.4 수요 예측 정확도 — 현재 수준과 개선 방향

> **핵심 메시지**: 예측 모델의 수요 순위 파악 능력(Spearman 0.478)은 확인되었습니다. "어떤 SC가 더 많이 팔릴지"의 순위를 부분적으로 맞추고 있으며, 특히 **판매 중간 구간(11~100개)에서 WAPE 31~32%의 양호한 정확도**를 보입니다. 고판매 구간의 과소추정 경향은 향후 개선 과제입니다.

#### 판매 구간별 예측 정확도 (WAPE)

<!-- 차트: 구간별 WAPE 바차트 -->

| 판매 구간 | WAPE | 평가 |
|----------|------|------|
| 1~10개 | 50.4% | 저판매 구간 — 소량 편차 영향 |
| **11~50개** | **31.6%** | **핵심 배분 구간 — 양호** |
| **51~100개** | **31.9%** | **핵심 배분 구간 — 양호** |
| 100개 이상 | 52.9% | 고판매 구간 — 과소추정 경향 |

판매 구간별로 예측 정확도를 분석하면, **11~50개 구간(WAPE 31.6%)**과 **51~100개 구간(WAPE 31.9%)**에서 안정적인 예측 성능이 확인됩니다. 이 구간은 보충배분의 핵심 의사결정 영역으로, 실제 운영에서 가장 빈번하게 배분 판단이 필요한 구간입니다.

| 지표 | 값 | 의미 |
|------|-----|------|
| Spearman (예측 vs 실판매) | **0.478** | 순위 파악 능력 |
| 중간 구간 WAPE | **31~32%** | 양호 |
| 고판매 구간 WAPE | **52.9%** | 개선 필요 |

> **개선 과제**: 고판매 구간(100개 이상)에서 WAPE 52.9%로 과소추정 경향이 나타납니다. 베스트셀러 예측 강화를 위한 스케일 보정이 선결 과제이며, 보정 후 ILP 재시뮬레이션을 통해 효과를 검증할 예정입니다.

### 4.5 기대 효과 종합

검증 결과를 종합하면, ILP 기반 자동 배분은 세 가지 구조적 장점을 통해 기존 수기 배분의 한계를 근본적으로 해소할 수 있습니다. 이는 단순한 자동화가 아니라, MD가 물리적으로 수행할 수 없었던 **전역 최적화**를 가능하게 하는 구조적 전환입니다.

**장점 1: 전역 최적화**

268개 매장 x 704개 스타일의 모든 조합을 동시에 최적화합니다. 주차당 3,000~4,400쌍에 달하는 Missed Pair를 체계적으로 해소합니다.

**장점 2: 판단 일관성**

동일한 인풋에 동일한 결과를 보장합니다. Spearman 상관이 주차마다 +0.36 ~ -0.24로 흔들리는 수기 배분의 불안정성을 해소합니다.

**장점 3: 다변수 동시 고려**

창고재고 + 매장재고 + 예측수요 + 매장 우선순위를 수학적으로 동시 최적화합니다. 과잉배분 방지 로직이 자동 작동합니다.
