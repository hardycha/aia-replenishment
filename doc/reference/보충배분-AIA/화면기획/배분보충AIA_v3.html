보충 배분 시스템 아키텍처 (3/26 미팅 기준)

보충값은 테이블에 저장하지 않고 실시간 계산으로 진행합니다. 매장 재고가 수시로 변동되고, 보충 대상 매장 리스트도 바뀌기 때문입니다. ML 예측값만 테이블에 적재하고, 보충값은 요청 시 계산합니다.

🧠 ML 예측 테이블

스키마: ML_DIST
테이블:
  • Pred_SC_total — SC 레벨 Total 예측
  • Pred_SC_shop — SC × 매장 레벨 예측
  • Pred_SCS_shop — SCS × 매장 (화면 표시용)

포함 정보: 예측 판매량, PR Ratio, 예측 기준일, 예측 기간(T+1~T+2)

배치: 매주 1회 (최신 데이터로 갱신)

⚡ ILP 보충 API

RT Off 버전 (우선 개발)
  • 물류 → 매장 단방향 보충
  • 물류 가용재고 상한 제약
  • 매장 재고 상한 제약
  • 정수 제약 (Integer)

RT On 버전 (향후 확장)
  • 매장 ↔ 매장 이동 허용
  • 음수값 = 해당 매장에서 출고
  • 색상으로 입고/출고 구분 표시

📦 SERP 연동

수신 데이터:
  • 매장 재고 (실시간)
  • 물류 재고 (실시간)
  • 매장 마스터, 매장 그룹

연동 방식: SQL API
담당: IT팀 (경중님) 확인 요청 중

향후 계획:
  • 현재: 별도 화면 (약식 시연용)
  • 향후: SERP 내 통합
