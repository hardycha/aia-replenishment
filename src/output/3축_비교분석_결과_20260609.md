## 3. ILP 배분 0의 원인 분석

### 3-1. 메커니즘

ILP 배분 공식: `Need = Forecast - CurrentStock`

```
실판매 128개/주
  ↓ 예측이 59.5%만 반영
예측 76.2개/주
  ↓ 292매장에 분산
매장당 예측 평균 0.26개/주
  ↓ 매장에 재고 1개만 있어도 Need = 0.26 - 1 = -0.74
ILP 배분 = 0
```

**예측 과소 × 매장 분산 효과** → ILP가 거의 항상 "배분 불필요"로 판단

### 3-2. 대표 사례: DXRS7R063_WHS

- 실판매: **52개/주** (31매장에서 활발히 판매 중)
- 예측: **23.5개/주** (실판매의 45%)
- 135매장에 분산 → 매장당 **0.17개/주**
- 매장에 재고 1개만 있어도 Need < 0
- AP에 55개 → **줄 수 있는데 안 줌**
- 재고 0인 매장: 240곳 (82%)
