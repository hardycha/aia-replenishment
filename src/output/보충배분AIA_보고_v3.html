Section 01
프로젝트 목적
1.1 현재의 문제

F&F의 보충배분은 현재 유통 MD가 매주 수기 엑셀로 집행하고 있습니다. 이 방식에는 세 가지 구조적 한계가 존재합니다.

1

담당자별 판단 기준 분산

담당자가 바뀌거나 SKU 수가 늘어날수록 배분 품질이 불안정해집니다. 동일한 상황에서도 담당자마다 판단 기준이 달라 결과가 다르며, 이 기준이 조직 내에 명시적으로 문서화되어 있지 않습니다.

2

베스트셀러 대응 구조적 취약

잘 팔리는 SC일수록 재고가 빠르게 소진되지만, 수기 배분으로는 판매 속도를 선제적으로 반영해 물량을 집중시키기 어렵습니다. 결과적으로 판매 기회 손실이 발생합니다.

3

반복 작업 공수 과다

스타일 수 x 매장 수 x 사이즈 수의 조합을 매주 반복 계산합니다. 단순 기준의 반복 판단에 MD가 시간을 쏟고 있어, 고부가가치 의사결정에 집중할 수 없습니다.

1.2 프로젝트 목적
"AI 기반 수요 예측 + 수학적 최적화로 보충배분 의사결정을 자동화하여, MD의 판단은 예외 처리와 최종 확인에 집중할 수 있는 구조를 만든다."
  • 베스트셀러 재고 부족 방지: 주간 판매 예측치를 기반으로 잘 팔리는 SC에 선제적으로 물량을 집중 배분
  • MD 배분 의사결정 효율화: 시스템이 최적 배분 수량을 제안하고, MD가 검토·조정·확정하는 구조로 전환

Section 02 — Core
효용성 검증 — MD가 하는 일을, AIA로 더 빠르게 할 수 있는가?
Discovery 의류 카테고리에 대해 3주간(W1~W3) MD의 실제 배분 데이터와 ILP 시뮬레이션 결과를 매장 재고·판매 데이터와 대조 검증했습니다.
!

검증 전 참고사항: 본 검증 기간(4월 말~5월 중순)은 26S 시즌 초입으로, 매장에 이미 시즌 초도물량이 투입되어 있어 보충배분 물량 자체가 크지 않은 시기입니다. 따라서 배분 건수와 수량의 절대 규모보다는, 배분의 방향성과 품질이 유사한 수준인지에 초점을 맞추었습니다. 26SS 판매가 본격적으로 쌓이면서 배분 규모가 커지는 시점에 대해서는 위클리 단위로 실배분과 ILP 결과를 지속 비교·적재하여 추이를 팔로우업할 예정입니다.

2.1 데이터 연동 검증

AIA 시스템은 기간계 시스템 SERP와의 데이터 인터페이스를 통해 매장재고, 창고재고, 판매이력을 직접 연동합니다. 데이터 정합성 검증이 완료되었습니다.

핵심 장점 1

유사한 품질, 압도적 속도

검증 결과 MD와 AIA의 배분 품질은 유사합니다. MD가 매주 수기로 수행하던 보충배분을, AIA 화면에서 훨씬 빠르고 간편하게 유사한 결과를 얻을 수 있습니다.

핵심 장점 2

판단 일관성

동일한 인풋에 동일한 결과를 보장합니다. MD의 컨디션이나 업무 부하와 관계없이, 매주 동일한 기준으로 배분이 실행됩니다.

핵심 장점 3

다변수 동시 고려

창고재고 + 매장재고 + 예측수요 + 매장 우선순위를 수학적으로 동시 최적화합니다. 과잉배분 방지 로직이 자동 작동합니다.

4.3 향후 확장 — RT(Rotation) 매장 간 재고 이동

현재 AIA는 창고 → 매장 방향의 보충배분에 집중하고 있습니다. 그러나 실제 유통 현장에서는 특정 매장에 재고가 잠겨 판매되지 못하는 반면, 같은 상품이 다른 매장에서는 품절인 상황이 빈번하게 발생합니다.

향후 RT(Rotation) 기능이 포함되면, 매장 간 재고 이동까지 최적화할 수 있습니다.

  • 잠자는 재고 활성화: 판매가 느린 매장에 잠겨 있는 재고를 잘 팔리는 매장으로 자동 이동 제안
  • 품절 기회손실 감소: 창고에 재고가 없더라도 타 매장에서 여유 재고를 확보하여 판매 기회 유지
  • 재고 회전율 개선: 전체 매장의 재고가 고르게 소진되도록 유도하여, 이월 재고 발생을 최소화
보충배분(창고→매장) + RT(매장→매장)가 결합되면, F&F의 재고 배분은 양방향 최적화 네트워크로 전환됩니다.
