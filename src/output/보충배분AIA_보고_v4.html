01

프로젝트 목적

1.1 현재의 문제

F&F의 보충배분은 현재 유통 MD가 매주 수기 엑셀로 집행하고 있습니다. 이 방식에는 세 가지 구조적 한계가 존재합니다.

①

담당자별 판단 기준 분산

담당자가 바뀌거나 SKU 수가 늘어날수록 배분 품질이 불안정해집니다. 동일한 상황에서도 담당자마다 판단 기준이 달라 결과가 다르며, 이 기준이 조직 내에 명시적으로 문서화되어 있지 않습니다.

②

베스트셀러 대응 구조적 취약

잘 팔리는 SC일수록 재고가 빠르게 소진되지만, 수기 배분으로는 판매 속도를 선제적으로 반영해 물량을 집중시키기 어렵습니다. 결과적으로 판매 기회 손실이 발생합니다.

③

반복 작업 공수 과다

스타일 수 x 매장 수 x 사이즈 수의 조합을 매주 반복 계산합니다. 단순 기준의 반복 판단에 MD가 시간을 쏟고 있어, 고부가가치 의사결정에 집중할 수 없습니다.

1.2 프로젝트 목적

"AI 기반 수요 예측 + 수학적 최적화로 보충배분 의사결정을 자동화하여, MD의 판단은 예외 처리와 최종 확인에 집중할 수 있는 구조를 만든다."
  • 베스트셀러 재고 부족 방지: 주간 판매 예측치를 기반으로 잘 팔리는 SC에 선제적으로 물량을 집중 배분
  • MD 배분 의사결정 효율화: 시스템이 최적 배분 수량을 제안하고, MD가 검토·조정·확정하는 구조로 전환

1.3 적용 범위

  • 초기 적용: Discovery 의류, MLB CP66, CP77 (M 브랜드)
  • 확장 대상: (Discovery, MLB, MKids, Duvetica, Sergio Tacchini)의 전체 아이템군

3.3 향후 확장 — RT(Rotation) 매장 간 재고 이동

현재 AIA는 창고 → 매장 방향의 보충배분에 집중하고 있습니다. 그러나 실제 유통 현장에서는 특정 매장에 재고가 잠겨 판매되지 못하는 반면, 같은 상품이 다른 매장에서는 품절인 상황이 빈번하게 발생합니다.

향후 RT(Rotation) 기능이 포함되면, 매장 간 재고 이동까지 최적화할 수 있습니다.

  • 잠자는 재고 활성화: 판매가 느린 매장에 잠겨 있는 재고를 잘 팔리는 매장으로 자동 이동 제안
  • 품절 기회손실 감소: 창고에 재고가 없더라도 타 매장에서 여유 재고를 확보하여 판매 기회 유지
  • 재고 회전율 개선: 전체 매장의 재고가 고르게 소진되도록 유도하여, 불필요한 잔여 재고 발생을 최소화
보충배분(창고→매장) + RT(매장→매장)가 결합되면, F&F의 재고 배분은 양방향 최적화 네트워크로 전환됩니다.
